联网设置
同步状态：本地 —
开启后：本机修改即自动上云；打开 / 切回本页自动拉取云端最新；多台设备填相同「同步标识」即共用同一份数据。
默认复用军机处的 workbench_state 表（字段 id / data / updated_at），无需新建表。
本 app 专属的一串随机标识，相当于「数据钥匙」。多台设备必须填完全一致才能共用数据，请勿外泄。
规则：云端为权威；本机一改即自动上云；打开页面 / 切回前台 / 每 30 秒自动拉取云端（正在输入时不打断）；本地有未上云改动时只推不拉，绝不用旧数据覆盖云端。
订单链自检（期初逐月推导）

9月的「月初库存 / 月初订单」不是单独录入的，而是自动等于上月的计算结果。任一年月的「可入库产量 / 累积订单 / 累积发货 / 差异调整」改了，都会顺着链条一路影响到后面所有月。下表列出全月链，红色 = 异常（待发订单或库存变负），点「跳转」回到对应月修正，9月 会自动跟着调回来。
